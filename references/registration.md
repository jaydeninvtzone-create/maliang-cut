# 新草稿首页登记

`register-draft DRAFT --draft-root ROOT --media-root MEDIA` 仅在Windows且剪映/CapCut进程全部退出时运行，不关闭或杀死任何进程。ROOT必须是本机现存草稿根目录，不修改系统设置。

只接受本包当前build生成的四文件新草稿：内容哈希、原素材哈希及路径范围必须一致。手工编辑过的草稿、旧包缺少哈希的草稿、重名目录、重复UUID/索引记录均拒绝。旧包需从原计划生成新版本，不补造回执。

仅接受顶层为all_draft_store数组、draft_ids字符串数组或不透明非负整数（排除bool）、root_path字符串的已知索引；已有条目字段遇未知格式拒绝。读取备份到ROOT/.maliang-register-backups，获得本包写锁，复制自有新草稿，再比较首页索引原始字节、重查进程状态，最后追加一条新记录；UUID数组追加自有UUID；非负整数的语义未确认，原样保留、不加1、不与条目数归一。已观察本机存在整数24与52条记录的合法现存状态，不能把它误判为条目计数。负数、bool和其他未知类型拒绝。此兼容行为已在剪映11.7.0.14652的合成短段完成首页显示、原生打开与导出验证；其他版本仍需验证。云端与账号字段留空/false/0，不克隆其他项目账号值。

同一索引只允许一个写入者；登记期间保持应用退出。独立工具若不遵守写锁仍可能构成外部竞争，因此遇并发变化立即停止，不覆盖更新后的索引。若复制已完成但最后比较失败，会留下自有未登记目录供检查，不自动删用户目录或回滚新索引。

备份是恢复证据，不是允许直接覆盖当前索引的理由；已有新改动时应对照后只修复本次自有记录。登记成功只表示写入首页条目，不表示原生打开/导出/审美验收通过。
