# 从素材到愿意发布的一版

## 执行顺序
1. inspect素材并听看代表片段，区分声音不清、原意不清、缺少证据。能修的直接处理；先尝试已有素材重排，仍讲不清才给最少补拍清单。不能假造结果。
2. 按真实逐字稿找结果、理由、操作和情绪。开头用能兑现的收益；不是每条都快速闪图。删除重复前核对保留哪一遍语气更好，不按静音长度删停顿。
3. 先做代表本条难点的10–20秒。已有风格授权可自行复核后展开；偏好不明时让用户看真实小样选择，不要求用户说特效术语。
4. 先把语义剪顺，再加动作和字幕。检查脸、字幕、操作区遮挡，优先换构图，不机械缩小字号。
5. 返修记录片段ID、时间码、修改目的及参数。保留已满意片段。变速后重算后续时间和字幕，不能只改speed。原生修改过的工程不用旧JSON覆盖。
6. 正常速度完整听看导出，再交付成片、工程及要求的封面标题。技术成功不等于质量通过。

## 按目的组合
| 观众需要 | 组合方式 | 不适合时 | 实现 |
|---|---|---|---|
| 看清操作 | 完整界面→推近→停留→返回 | 放大仍糊，换清晰局部录屏 | 位置/缩放关键帧 |
| 看见改善 | 同尺度前后切换→变化处停留 | 信息密则分步比较，音量保持公平 | 裁切、多轨位置 |
| 看人和结果 | 结果主画面→人物移位→结果全屏 | 面积不够就撤小窗 | transform/keyframes；抠像另做原生验证 |
| 跟上步骤 | 当前操作→对应字幕→下一步 | 不持续旋转装饰 | 裁切、字幕、位置 |
| 感受情绪 | 表情→自然停顿→接下一句 | 真情绪不需音效补戏 | 原声裁切 |
| 浏览成果 | 少量有区别作品→重点停留 | 读不完则减页/放慢 | 时段排列，核实际帧数 |
| 理解抽象关系 | 分层示意→一次变化→真实结果 | 动作说不出作用就简化 | 原生优先，确有缺口再外部 |
| 听清人声 | 先定人声→去噪→可选避让 | 损伤音色则回退，不默认加配乐 | 原生声音处理并回听 |

## 外部能力与偏好
图像、三维、动画、音乐服务仅在内容需要时使用。先检查当前宿主工具、账户、成本和输出许可；包内不附这些服务。不能从作者私有路径加载插件或假装执行成功；不能复制无再分发许可的代码。外部素材回同一剪映工程，记录采用原因。
preferences.json只保存本项目明确确认的偏好和来源。字体、原声、禁用项可以延续；人物位置、速度、剪点按新素材重新决定。旧方案没有优先于新内容的权利。
