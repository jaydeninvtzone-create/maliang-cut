# maliang-cut · 马良剪辑

版本：0.1.4（预发布）

仓库：https://github.com/jaydeninvtzone-create/maliang-cut

一个面向 Codex 的内容驱动剪辑技能。把素材、具体想法和修改要求交给它，由 Codex 编排，剪映承担原生编辑。公开包不含作者私有素材、项目经验库或历史聊天。

## 安装

下载并解压此仓库，使用 Python 3.12+：

```powershell
python install.py --target "$env:USERPROFILE/.codex/skills/maliang-cut"
python -m pip install -r requirements.txt
python scripts/maliang.py doctor
```

上面的相对命令在解压目录运行。安装后应先读 `$env:USERPROFILE/.codex/skills/maliang-cut/SKILL.md`，CLI 位于该目录下的 `scripts/maliang.py`，例如：`python "$env:USERPROFILE/.codex/skills/maliang-cut/scripts/maliang.py" doctor`。Codex CLI若不具备电脑控制工具，安装技能不会自动获得该能力。

安装器拒绝覆盖已有技能。依赖安装在当前 Python 环境，建议先建虚拟环境。FFmpeg/FFprobe 需自行安装并加入 PATH，或通过命令的 `--ffmpeg`/`--ffprobe` 指定。剪映需单独安装。使用能操作本机应用的 Codex 宿主才能完成原生打开、效果编辑和导出；只有代码运行能力时，不承诺无人值守全流程。

## 当前能力

- 探测素材、校验片段范围与时间线。
- 新建剪映草稿：源时段裁切、速度、原音、多视频层、静态变换、可编辑字幕。
- 生成受限粗剪预览、导出文件解码/时长检查。
- 通过宿主电脑控制能力完成原生效果、导出和观看复核。

有可选离线ASR命令，但不内置或下载模型权重；没有全剪映功能自动控制器，没有绕过登录/VIP的实现。旧导出控制器已从执行入口移除。草稿结构测试不证明任意剪映版本加载兼容；在用户实际版本先做短段验证。

## 开发与发布

`python -m unittest discover -s tests -v`；`python tools/release.py --out ../maliang-cut-release.zip`。
发布工具只收录人工维护的 release-files.json 文件清单，拒绝未登记文件进入发布包，并对清单内文件做敏感串检查。自动扫描不可能覆盖所有私人内容，发布前仍须审阅文件清单与差异。不要从私人仓库直接改成公开；使用本干净导出目录的新历史。

项目代码采用 Apache-2.0；第三方来源和必要署名保留于 NOTICE/vendor，不要求用户调用第二个技能。FFmpeg、剪映、Python和宿主组件不随本包分发。



## 从草稿到剪映首页

`build` 生成在独立目录，不能仅把文件存在当作能在剪映打开。先正常退出剪映，然后使用：

```powershell
python scripts/maliang.py register-draft "生成的草稿目录" --draft-root "剪映实际草稿根目录" --media-root "本次授权素材目录"
```

实际草稿根目录应来自本机剪映设置或既有目录，内部须已有 `root_meta_info.json`；不能猜路径后新建空索引。成功登记后再启动剪映，在首页按计划的 `name` 打开。原生编辑、导出与正常速度观看仍须另行完成。详细行为和恢复边界见 [登记合同](references/registration.md)。

## 已验证的范围

2026-11-03，在Windows、剪映11.7.0.14652上，用本包生成的合成测试短段完成了：首页登记、原生打开、查看第二段的位置/缩放/1.25倍速/字幕、在原生界面修改字幕并保存、原生导出。导出为1920×1080、30fps、H264/AAC，108视频帧，3.621995秒，完整解码通过。40项程序测试另行覆盖计划、越界、重复写入和登记的异常情况。

这个结果证明该版本下的基础草稿接入、原生修改与导出链路可行；不能证明真人语义剪辑、完整原声审听、无人值守整片、所有剪映版本或所有特效可用。新的目标版本和必要效果仍需短段验证。该合成测试视频和本机验证记录不随公共包发布。

## 可选：本地原始转写

同一技能内运行 `asr`，不调用另一个技能，也不连接付费接口。先阅读 [ASR范围与许可](references/asr.md)。可选依赖用 `python -m pip install -r requirements-asr.txt` 安装，模型由使用者另行准备；本包不下载或分发权重。

```powershell
python scripts/maliang.py asr "授权的短PCM.wav" --model-dir "自备的模型目录" --out "新的转写输出目录" --language zh
```

仅支持Windows、16kHz单声道16位PCM WAV、单次不超过30秒、CPU单线程。输出原始文本和模型token起点估计，不提供已验收的逐字结束时间或成品SRT，不自动删除口误、重复或改写原话。长原片需在保留原时间偏移的工作副本上分块，完整听读后按语义剪，不把30秒分块边界当剪点。

本版本ASR已完成一次4.133秒合成中文短句的真实CPU单线程调用。原始输出的18个汉字与输入句一致，逗号和句号未保留，并返回18个token起点估计。此结果只证明这次短句调用；真人、长片、词尾对齐、成品SRT和语义删改仍未验证。

镜头计划使用v2：在原有目的/方法/理由基础上补验证动作。只有确有取舍时才列备选；简单直切说明无需另一方案的原因即可。validate/build会实际检查这些字段，回执关联片段ID与落盘参数；机器检查不判断审美优劣。
