# maliang-cut · 马良剪辑

**把原片交给 Codex，在剪映里得到一版能继续改的视频。**

删掉重说的一句，保留说话的劲儿；讲到操作时给观众看操作，讲到结果时把结果放大。临时说一句“这里快一点，人物挪到右下角”，就沿着这一段继续改。

maliang-cut 把素材检查、剪辑计划、可编辑草稿和导出检查放进一个 Codex 技能。画面由内容决定，具体剪辑仍由 Codex 和本机剪映协作完成。当前版本 **0.1.5 · 预发布**，优先支持 Windows。

## 你可以拿它做什么

| 交给它 | 希望拿回来的东西 | 怎样接着改 |
| --- | --- | --- |
| 一段口播和操作录屏 | 保留原声、去掉确认过的重复、按讲解安排画面 | “这句停顿留着，后面重说的删掉” |
| 一个已核对的剪辑计划 | 多轨道剪映草稿、独立字幕、裁切和位置参数 | “12秒这里加快一点，别挡住按钮” |
| 一份导出视频 | 解码、时长检查，再完整听看 | “结尾多留半秒，让最后一个字说完” |

这些是使用场景，不是自动识别效果的成功率承诺。口误判断、真实听看、原生高级效果和封面标题由 Codex 按素材执行；命令行工具负责已实现的检查与草稿生成。

例如，原片中你把同一句话说了两遍。先核对保留哪一遍，再生成新版本；你补一句“前一遍语气更好”，就改这一个决定。已经在剪映中手工调整的工程继续在剪映修改，不用旧计划覆盖。

## 复制这一段，开始第一条

把下面提示词连同**素材目录**发给 Codex。已有账号和电脑控制工具按当前环境使用；技能本身不会给普通 CLI 增加电脑控制权限。

> 请读取 https://github.com/jaydeninvtzone-create/maliang-cut 的 README.md 和 SKILL.md，安装 maliang-cut，并用同一个 Python 环境检查依赖、运行 doctor。已有同名技能时保留旧版，比较后再升级。用这套技能把我的授权素材剪成约2分钟的抖音视频：保留原声和语气，核对后删除口误与无意义重复，前10秒优先呈现这条内容的结果和收获，画面随内容决定。先做关键片段确认路线，再粗剪、精剪、导出；交付成片、可编辑工程、横竖封面、长短标题。我授权本次任务所需的本机操作，不发布、不付费。检查当前宿主能否操作剪映；缺少转写或控制能力时说明具体缺口和可以继续完成的部分。素材目录：……。我这条的新想法：……。

局部修改可以直接说：

> 00:12—00:16 这段改成1.25倍速，人物放右下角，别遮住操作按钮。其他段落保持。完成后让我对照看这一段。

## 本机需要什么

- Python 3.12+、FFmpeg/FFprobe、单独安装的剪映。
- 能读取素材和运行代码的 Codex；原生操作、导出需要当前宿主提供电脑控制工具。
- 可用的转写来源。可选离线 ASR 需要另备模型，不随仓库下载权重。

下载解压仓库，在解压目录运行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe install.py --target "$env:USERPROFILE/.codex/skills/maliang-cut"
.venv/Scripts/python.exe "$env:USERPROFILE/.codex/skills/maliang-cut/scripts/maliang.py" doctor
```

后续继续用这个虚拟环境的 Python。FFmpeg 不在 PATH 时，doctor 支持 `--ffmpeg "实际ffmpeg.exe路径" --ffprobe "实际ffprobe.exe路径"`。缺少必需项会返回非零退出码和修复提示；检查通过只代表这些本地前提就绪。

安装器不覆盖已有目录。第一次启动让 Codex 先读已安装的 `SKILL.md`。[命令与草稿打开步骤](references/getting-started.md)包含从素材检查到首页登记的具体命令。

## 目前能做到哪一步

代码支持素材探测、计划检查、时段裁切、速度与原音、多视频层、位置/缩放、可编辑字幕、新草稿登记、受限粗剪预览及导出解码检查。高级效果按实际需要在剪映执行，保留可改的工程。

已在 Windows / 剪映 11.7.0.14652 用合成短段跑通草稿登记、原生修改字幕、保存和导出；可选 ASR 跑通一次4.133秒合成中文短句。**真人整片语义剪辑、所有剪映版本、所有特效和无人值守整片没有因此获得验证。** [测试范围](references/validation.md)写明具体边界。

离线 ASR 当前接收不超过30秒的16kHz单声道16位 PCM WAV，保留识别原文和 token 起点估计；不能直接当精确逐字字幕或自动删口误结果。长片要保留分块偏移并回听。[ASR 使用与模型许可](references/asr.md)。
